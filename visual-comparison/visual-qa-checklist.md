# Visual Quality-Assurance Checklist

Use this checklist before delivering a visual comparison. Mark each item only after checking the actual files.

## Prompt fidelity
- [ ] Both panels use the required top-down/overhead viewpoint.
- [ ] Rainforest panel clearly shows dense, overlapping canopy.
- [ ] Desert panel clearly shows exposed ground and sparse, separated vegetation.
- [ ] Labels and callouts correspond to visible evidence.
- [ ] No unrequested statistics or claims were added.

## Research and factual accuracy
- [ ] Original source page has been opened and reviewed.
- [ ] Caption, location, and context have been checked.
- [ ] Image has not been mislabelled based only on appearance.
- [ ] Any factual text has a reliable supporting source.
- [ ] Uncertainty and representativeness limits are disclosed.

## Rights and provenance
- [ ] Creator and original source URL are recorded.
- [ ] License or usage terms are checked for portfolio use.
- [ ] Attribution requirements are followed.
- [ ] Download date and any restrictions are recorded.
- [ ] No watermark has been removed and no access restriction bypassed.

## Layout and annotation
- [ ] Panel dimensions and margins are consistent.
- [ ] Crops do not misleadingly exaggerate the difference.
- [ ] Text is readable at intended display size.
- [ ] Callouts do not hide key features.
- [ ] Contrast is sufficient and color is not the only information cue.
- [ ] Overall layout is uncluttered and balanced.

## Export and file management
- [ ] Final export dimensions and file format match the brief.
- [ ] Export has been inspected at full size.
- [ ] No accidental borders, clipping, artifacts, or missing fonts.
- [ ] Working file remains layered/editable.
- [ ] File names are descriptive and versioned.
- [ ] Source log and final files are stored in the expected folder.
